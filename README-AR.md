# موقع مكتب المحامي ثامر بشير السويدي — GitHub Pages

## الرفع الصحيح

ارفع **محتويات هذه الحزمة** إلى جذر مستودع GitHub اسمه `landing-pages`، وليس مجلد الحزمة نفسه.

في GitHub افتح `Settings → Pages` ثم اختر:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

رابط الموقع المتوقع:
`https://orvelaonline-droid.github.io/landing-pages/`

ملف `404.html` نسخة من التطبيق، وهو مطلوب حتى تعمل المسارات الداخلية عند التحديث المباشر على GitHub Pages.
